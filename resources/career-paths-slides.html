02

PATH 01 · WEB DEVELOPMENT 🌐

Build what people
open in a browser.

WHAT IS IT?

Frontend, backend, full-stack

The part you see and click, the part that stores data and logins — or both together.

IS THIS ME?

You like fast results

You write code, refresh the page and immediately see what changed. Creativity meets logic.

SKILLS IN ORDER

HTML → CSS → JavaScript

Then Git & GitHub, a framework like React, and backend basics later.

START THIS WEEK

freeCodeCamp · CodePen

Build an "About Me" page, a colour-changing button or a five-question quiz.

03

PATH 02 · MOBILE DEVELOPMENT 📱

Apps that live
in a pocket.

WHAT IS IT?

Android and iOS

Build the apps people tap and swipe every day — many tools now build for both at once.

IS THIS ME?

You imagine better apps

You want friends to install something you made, and you enjoy designing for small screens.

SKILLS IN ORDER

Logic → Flutter or Kotlin

Programming basics, then UI design, saving data and Git & GitHub.

START THIS WEEK

MIT App Inventor

Drag blocks to build a digital business card, a bill-splitter or a quiz app.

04

PATH 03 · CYBERSECURITY 🔐

Digital guardians.
Legally curious.

WHAT IS IT?

Blue team & red team

Defend systems, or hack them on purpose with permission to find holes first.

IS THIS ME?

You love puzzles

You ask "how could someone break this?" and you care about protecting people online.

SKILLS IN ORDER

Networks → Python → Linux

Then core security ideas, capture-the-flag practice, and ethics.

START THIS WEEK

TryHackMe · picoCTF

Golden rule: only ever test systems you own or have written permission to test.

05

PATH 04 · AI & MACHINE LEARNING 🤖

Teach a computer
from examples.

WHAT IS IT?

Learning, not rules

Instead of writing every rule, you show thousands of examples and let the model find the pattern.

IS THIS ME?

You wonder how ChatGPT works

You enjoy patterns, experiments and using powerful technology responsibly.

SKILLS IN ORDER

Python → data → models

Statistics basics, pandas, scikit-learn, and AI ethics. You need curiosity before maths genius.

START THIS WEEK

Teachable Machine

Train a gesture recogniser in your browser with zero code, then try Elements of AI.

06

PATH 05 · DATA ANALYSIS & SCIENCE 📊

Find the story
inside the numbers.

WHAT IS IT?

Analyst and scientist

Answer questions with charts and reports — then predict what happens next.

IS THIS ME?

You ask "why?"

You like tidying messy things, spotting patterns and explaining them clearly.

SKILLS IN ORDER

Sheets → stats → Python → SQL

Then a dashboard tool like Power BI, Tableau or Looker Studio.

START THIS WEEK

Survey your class

Chart the results in Google Sheets, then explore an open dataset on Kaggle.

07

PATH 06 · CLOUD & DEVOPS ☁️

Keep the internet
always on.

WHAT IS IT?

Someone else's computers

Cloud engineers run the servers; DevOps engineers ship new code safely and quickly.

IS THIS ME?

You organise and automate

You stay calm under pressure and like being the person who keeps things working.

SKILLS IN ORDER

Internet → Linux → cloud

Command line, AWS, Google Cloud or Azure free tiers, Git, then Docker and CI/CD.

START THIS WEEK

GitHub Pages

Put a page live on the internet for free, and learn your first Linux commands: ls, cd, mkdir.

08

PATH 07 · UI/UX DESIGN 🎨

Make technology
work for humans.

WHAT IS IT?

Look and feel

UI is colours, buttons and layout. UX is whether using it actually makes sense.

IS THIS ME?

You notice confusing design

You care how people feel, enjoy making things beautiful, and solve problems creatively.

SKILLS IN ORDER

Design thinking → Figma

Colour, spacing and type, wireframes, prototypes, user testing — coding is optional.

START THIS WEEK

Design a sign-up screen

Sketch on paper, rebuild it in Figma, then link two screens so the buttons work.

09

PATH 08 · GAME DEVELOPMENT 🎮

Code, art and story
in one world.

WHAT IS IT?

A team of makers

Programmers, designers, artists and sound designers — indie developers start by doing a bit of everything.

IS THIS ME?

You imagine your own games

You love creativity, storytelling and logic, and you enjoy experimenting until it feels fun.

SKILLS IN ORDER

Scratch → Godot or Unity

Logic first, then Python with Pygame or C# with Unity, plus game-design instincts.

START THIS WEEK

Make a sprite move

Build Pong, a maze game or "catch the falling mango", then share it for feedback.

10

PATH 09 · QUALITY ASSURANCE 🧪

Break it kindly.
Before users do.

WHAT IS IT?

Manual and automated

Click through everything by hand, then write code that runs the checks for you.

IS THIS ME?

You notice what's off

Detail, patience and curiosity — QA is one of the friendliest ways into tech with no coding at first.

SKILLS IN ORDER

Test cases → bug reports

Clear writing, then a little Python or JavaScript, Playwright or Selenium, and Git.

START THIS WEEK

Write one bug report

Steps, expected result, actual result. Then write a test plan for a login screen.

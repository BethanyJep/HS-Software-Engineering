# Holiday Build Challenge 🚀

> **One holiday. Seven fields. Seven small things you can build.**

This challenge is for students who want to try the seven career paths that interest them.
You do **not** need to finish every project. Choose at least one field, follow the steps,
and share what you made before the holidays end.

Every project is designed for a beginner. A simple working project is better than a large
unfinished one.

---

## 🌱 New to coding? Start here first

If you have never written code before, spend **an hour or two** here before your project.
These are free, friendly, and made for complete beginners — no experience needed.

| Resource | What it teaches | Why it's great for beginners |
|---|---|---|
| [Scratch](https://scratch.mit.edu/) | Coding logic with drag-and-drop blocks | No typing code — you *see* how programs think |
| [Code.org – Hour of Code](https://code.org/learn) | A fun 1-hour intro to coding | Short, guided, and rewarding |
| [freeCodeCamp](https://www.freecodecamp.org/learn) | Real HTML, CSS & JavaScript | Free, hands-on, works in your browser |
| [Khan Academy – Intro to Programming](https://www.khanacademy.org/computing/computer-programming) | Drawing and animation with code | Clear videos you can pause and replay |
| [SoloLearn](https://www.sololearn.com/) | Bite-sized coding lessons on your phone | Learn in short bursts anywhere, even on a small screen |
| [Typing Club](https://www.typingclub.com/) | Faster, more accurate typing | A quiet superpower that makes everything else easier |

> 💡 **How to use this:** Try **Scratch** or the **Hour of Code** first to understand what
> code *is*. Then pick your project below. You will learn the rest **while building** — that
> is how real developers learn.

**Two habits that will help you all holiday:**
- When something breaks, read the error slowly. Breaking things is normal — it's called *debugging*.
- When stuck for more than 30 minutes, search your exact question or ask a friend. Everyone does this.

## Before you begin

1. Choose the project that sounds most exciting.
2. Set aside **two or three focused sessions** of 30–60 minutes.
3. Start with the smallest version (the **MVP**).
4. Save your work and take screenshots as you go.
5. Show it to one person and ask: *"What should I improve?"*

> You can use tutorials and AI tools to learn, but make sure you understand and can explain
> the work you submit. Never share private passwords, personal information, or someone else's
> photos without permission.

## 1. Web Development — My Helpful School Website 🌐

### Build this

Create a one-page website that helps a student find something useful, such as study tips,
school events, revision resources, or career paths.

### Use

[CodePen](https://codepen.io/) or [GitHub Pages](https://pages.github.com/). You only need
HTML and CSS to begin. Add JavaScript if you want an interactive feature.

**▶️ Learn the basics first:**
[freeCodeCamp: Responsive Web Design](https://www.freecodecamp.org/learn/2022/responsive-web-design/) ·
[W3Schools HTML tutorial](https://www.w3schools.com/html/) ·
[📖 Full field guide](web-development.md)

### Build it in steps

- [ ] Add a clear title, short introduction, and at least three sections.
- [ ] Add a navigation menu that jumps to each section.
- [ ] Add colours, spacing, and readable fonts with CSS.
- [ ] Add one image or illustration with useful alternative text.
- [ ] Add one interactive feature: a quiz, a show/hide tip, or a colour-changing button.
- [ ] Ask someone to use it on a phone and improve one confusing part.

### Done means

A visitor can open the page, understand what it is for, and use at least one helpful feature.

## 2. Mobile Development — My Daily Helper App 📱

### Build this

Create a simple phone app that helps with one daily task: a study timer, homework checklist,
water reminder, mood check-in, or revision flashcards.

### Use

[MIT App Inventor](https://appinventor.mit.edu/) is recommended because you can build with
blocks in a browser. Use [Flutter](https://docs.flutter.dev/get-started/codelab) if you
already know some programming.

**▶️ Learn the basics first:**
[App Inventor beginner tutorials](https://appinventor.mit.edu/explore/ai2/tutorials) ·
[Build your first app (video)](https://www.youtube.com/watch?v=DmZ4Ua4vfFo) ·
[📖 Full field guide](mobile-development.md)

### Build it in steps

- [ ] Sketch the app's screens on paper.
- [ ] Create a home screen with a title and clear buttons.
- [ ] Add one input, such as a task, subject, time, or mood.
- [ ] Make the main button respond when tapped.
- [ ] Show a useful result, such as a completed task or study message.
- [ ] Test it on a phone or emulator and fix one problem.

### Done means

Someone can open the app, complete its main task, and understand what to tap next.

## 3. Cybersecurity — Stay Safe Online Toolkit 🔐

### Build this

Create an online safety toolkit that teaches students how to recognise phishing, use strong
passwords, and protect their accounts.

### Use

Start with a [Google Slides](https://slides.google.com/) presentation, a one-page website,
or a small Python program. Only practise security on your own accounts or approved training
platforms.

**▶️ Learn the basics first:**
[TryHackMe: Intro to Cyber Security](https://tryhackme.com/r/module/introduction-to-cyber-security) ·
[picoCTF beginner challenges](https://picoctf.org/) ·
[📖 Full field guide](cybersecurity.md)

### Build it in steps

- [ ] Write five online safety rules in your own words.
- [ ] Collect three fake phishing examples (do not include real private messages).
- [ ] Explain at least four warning signs in each example.
- [ ] Build a password-strength checker using example passwords only, never real passwords.
- [ ] Add a short five-question safety quiz with answers.
- [ ] Ask a family member or friend to take the quiz and improve one explanation.

### Done means

A student who uses your toolkit can identify common phishing warning signs and name three
ways to protect an account.

> **Safety rule:** Do not scan, guess passwords for, or attack any website, account, or Wi-Fi
> network without clear written permission. Use [picoCTF](https://picoctf.org/) or
> [TryHackMe](https://tryhackme.com/) for legal practice.

## 4. Artificial Intelligence & Machine Learning — Teach an AI 🤖

### Build this

Train a small AI model to recognise something useful, such as hand gestures, recyclable
objects, or different sounds.

### Use

[Google Teachable Machine](https://teachablemachine.withgoogle.com/) is recommended because
it works in a browser and needs no code. Use [Kaggle Learn](https://www.kaggle.com/learn)
if you want a coding challenge.

**▶️ Learn the basics first:**
[Teachable Machine tutorial (video)](https://www.youtube.com/watch?v=DFBbSTvtpy4) ·
[Elements of AI (free course)](https://www.elementsofai.com/) ·
[📖 Full field guide](artificial-intelligence.md)

### Build it in steps

- [ ] Choose two or three categories for your AI to recognise.
- [ ] Collect examples for each category with permission.
- [ ] Train the model and test it with examples it has not seen.
- [ ] Record where it gets confused.
- [ ] Improve it by adding more varied examples.
- [ ] Make a one-page report: what it learned, what it got wrong, and why fairness matters.

### Done means

Your model can recognise at least two categories, and you can explain that its results depend
on the examples used for training.

> Do not upload faces, voices, names, or other personal data without clear permission. Use
> objects, drawings, or your own hands instead.

## 5. Data Analysis & Data Science — Find a Story in Data 📊

### Build this

Run a small, anonymous class or family survey and turn the answers into charts and a short
story about what you discovered.

### Use

[Google Forms](https://forms.google.com/) and [Google Sheets](https://sheets.google.com/)
are enough. Do not collect names, phone numbers, health information, or other sensitive data.

**▶️ Learn the basics first:**
[Google Sheets training & help](https://support.google.com/a/users/answer/9282959) ·
[Kaggle: Intro to Programming](https://www.kaggle.com/learn/intro-to-programming) ·
[📖 Full field guide](data-analysis.md)

### Build it in steps

- [ ] Choose one question, such as favourite study method or transport to school.
- [ ] Ask at least 10 people, explaining how the answers will be used.
- [ ] Put the answers into a spreadsheet and remove identifying information.
- [ ] Use `COUNT`, `AVERAGE`, or percentages to summarise the results.
- [ ] Create two charts with titles and labels.
- [ ] Write three sentences: what surprised you, what the data shows, and what it does not prove.

### Done means

Someone who did not collect the data can understand your charts and your main conclusion.

## 6. UI/UX Design — Improve an App Screen 🎨

### Build this

Design a simple app that solves a student problem, such as finding school events, revising
for exams, or reporting a lost item.

### Use

[Figma](https://www.figma.com/) is recommended. Paper sketches are also a real and valuable
first step.

**▶️ Learn the basics first:**
[Figma for beginners (official)](https://help.figma.com/hc/en-us/articles/14563969806359-Figma-for-beginners-Explore-designs-part-1-of-4) ·
[Google UX Design (audit free)](https://www.coursera.org/professional-certificates/google-ux-design) ·
[📖 Full field guide](ui-ux-design.md)

### Build it in steps

- [ ] Ask two people what they find difficult about the chosen problem.
- [ ] Sketch three screens on paper: home, main task, and success/confirmation.
- [ ] Recreate the screens in Figma with clear headings and buttons.
- [ ] Link the screens into a clickable prototype.
- [ ] Ask two people to complete the main task without coaching them.
- [ ] Improve one part they found confusing.

### Done means

A person can click through the prototype and complete the main task without needing you to
explain every screen.

## 7. Game Development — A Game with a Purpose 🎮

### Build this

Make a short game that teaches or practises something: Kenyan history, road safety,
financial literacy, vocabulary, or environmental awareness.

### Use

[Scratch](https://scratch.mit.edu/) is recommended. Move to [Godot](https://godotengine.org/)
only if you already feel comfortable with Scratch or programming.

**▶️ Learn the basics first:**
[Scratch: Getting Started guide](https://scratch.mit.edu/projects/editor/?tutorial=getStarted) ·
[Scratch tutorials library](https://scratch.mit.edu/ideas) ·
[📖 Full field guide](game-development.md)

### Build it in steps

- [ ] Write the goal in one sentence: *"The player wins by..."*
- [ ] Add a player or character and one way to control it.
- [ ] Add one challenge, question, or obstacle.
- [ ] Add a score, timer, or progress message.
- [ ] Add a clear win or finish screen.
- [ ] Let two people play and change one thing based on their feedback.

### Done means

A new player knows what to do, can play from beginning to end, and learns or practises the
chosen topic.

## Your holiday showcase

Before school starts, prepare a tiny showcase for your facilitator, family, or friends:

- **Project name:** What did you call it?
- **Problem or purpose:** Who is it for?
- **Demo:** Show the main feature in 60–90 seconds.
- **Learning:** What did you learn or find difficult?
- **Next step:** What would you add with one more week?

### Share your evidence

- [ ] A link, file, prototype, or video of your project
- [ ] Two screenshots
- [ ] A short explanation in your own words
- [ ] One piece of feedback you received
- [ ] One improvement you made

> Finished is better than perfect. Building one small thing is a real start to a career.

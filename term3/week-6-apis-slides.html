04

STEP 4 OF 11 · SCRIPT.JS · ADD BELOW

Fetch the data.

  1. Add this function at the bottom.
  2. The last line runs it when the page opens.
  3. Watch the preview.

script.js · add at the bottom

async function loadWeather() {
  status.textContent = "Loading weather…";

  const response = await fetch(weatherUrl);
  const data = await response.json();

  const temp = data.current.temperature_2m;
  const unit = data.current_units.temperature_2m;
  status.textContent = `Nairobi: ${temp} ${unit}`;
}

loadWeather();

✅ Check: “Loading weather…” then something like Nairobi: 21.4 °C.

await waits for the internet. async lets a function use await.

05

STEP 5 OF 11 · SCRIPT.JS · REPLACE

Handle errors.

  1. Replace your whole loadWeather function with this version.
  2. Keep the loadWeather(); line below it.
  3. Watch the preview.

script.js · replace loadWeather

async function loadWeather() {
  status.textContent = "Loading weather…";
  try {
    const response = await fetch(weatherUrl);
    if (!response.ok) {
      throw new Error(`Request failed: ${response.status}`);
    }
    const data = await response.json();
    const temp = data.current.temperature_2m;
    const unit = data.current_units.temperature_2m;
    status.textContent = `Nairobi: ${temp} ${unit}`;
  } catch (error) {
    status.textContent = "Weather is unavailable. Please try again later.";
    console.error(error);
  }
}

✅ Check: the temperature still appears, exactly as before.

try runs the risky code. catch shows a friendly message if it fails.

09

STUCK? · COMMON FIXES

Check the Console.

  • “Weather is unavailable”Check your internet, then compare the address with Step 3 letter by letter.
  • Stuck on “Loading…”Open the Console tab and read the first red error.
  • “undefined” on the pageA name is misspelled, such as temperature_2m or current_units.
  • “await is only valid…”Put async before function loadWeather().

Open the API address in a tab again. If it shows JSON, the API works and the bug is in your code.

11

STEP 10 OF 11 · SAFE API USE

Keep secrets out.

  1. Use APIs that need no key, like Open-Meteo.
  2. Never type a password, API key or token into your code.
  3. Request only the data your page shows.
  4. If a site asks for payment details, stop and choose a different API.

✅ Check: your script.js contains no keys, passwords or private details.

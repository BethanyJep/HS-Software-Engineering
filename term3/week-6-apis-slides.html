APIs and Fetch

HOLIDAY SELF-STUDY · WEEK 2

Ask for data.
Show it clearly.

Use fetch, async and await to display public or project data in your individual capstone.

Use this with the written guide Lesson 6: APIs and Fetch and the Holiday Self-Study Pack.

Individual capstoneGrade 10 · Term 3
01

STEP 1 · ~15 MIN

Like ordering
at a restaurant.

Your page → request → API
Your page ← JSON response ← API

The request asks for data. The response returns JSON your JavaScript can read.

02

SAFETY CHECK · ~10 MIN

Public data.
Private secrets.

  • Never publishPasswords, API keys, tokens or private personal information.
  • Ask lessRequest only the data your page needs.
  • Plan fallbackShow a useful message when internet or service fails.

Open APIs with no key, like Open-Meteo, are safest for browser practice.

03

STEP 2 · HTML

Start with
a status.

<p id="weather-status" aria-live="polite"></p>
<button id="refresh" type="button">Refresh</button>

The status paragraph tells the user when data is loading, ready or unavailable.

04

BUILD · JAVASCRIPT

Wait for
the response.

const status = document.querySelector("#weather-status");

async function loadWeather() {
  status.textContent = "Loading weather…";
  const response = await fetch(weatherUrl);
  const data = await response.json();
  status.textContent = `Nairobi: ${data.current.temperature_2m} °C`;
}

async lets the function use await. await pauses until fetch or json is ready.

05

BUILD · NO KEY NEEDED

Coordinates choose
the place.

const weatherUrl =
  "https://api.open-meteo.com/v1/forecast" +
  "?latitude=-1.2864&longitude=36.8172" +
  "&current=temperature_2m";

loadWeather();

Open the URL in a new tab. Find current.temperature_2m in the raw JSON.

06

BUILD · FRIENDLY FAILURE

Errors should
not blank the page.

try {
  const response = await fetch(weatherUrl);
  if (!response.ok) {
    throw new Error(`Request failed: ${response.status}`);
  }
  const data = await response.json();
  status.textContent = `Nairobi: ${data.current.temperature_2m} °C`;
} catch (error) {
  status.textContent = "Weather is unavailable. Try again later.";
  console.error(error);
}

A helpful error message is better than a silent broken feature.

Use services
respectfully.

  • FallbackDesign loading, empty and error states.

If a site asks for payment details or a secret key, choose a different practice API.

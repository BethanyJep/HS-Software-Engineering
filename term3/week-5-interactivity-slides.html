03

STEP 3 OF 11 · SCRIPT.JS

Store data. Find elements.

  1. Click script.js.
  2. Type the array of resources.
  3. Type the five querySelector lines.
  4. Open the Console tab under the preview.

script.js

const resources = [
  { title: "Revision group" },
  { title: "Science fair" },
  { title: "Coding club" }
];

const searchInput = document.querySelector("#search");
const searchButton = document.querySelector("#search-button");
const resetButton = document.querySelector("#reset");
const status = document.querySelector("#status");
const results = document.querySelector("#results");

✅ Check: the page has not changed and the Console shows no red errors.

Each "#name" must match an id in index.html exactly.

04

STEP 4 OF 11 · SCRIPT.JS · ADD BELOW

Show the results.

  1. Add this function below your Step 3 code.
  2. The last line runs it once with every resource.
  3. Watch the preview.

script.js · add at the bottom

function showResults(items) {
  results.replaceChildren();
  for (const item of items) {
    const listItem = document.createElement("li");
    listItem.textContent = item.title;
    results.append(listItem);
  }
  if (items.length === 0) {
    status.textContent = "No resources match your search.";
  } else {
    status.textContent = `${items.length} result(s) found.`;
  }
}

showResults(resources);

✅ Check: three resources in a list and 3 result(s) found.

textContent shows text safely. Never put user text into innerHTML.

05

STEP 5 OF 11 · SCRIPT.JS · ADD BELOW

Make Search work.

  1. Add this code at the bottom.
  2. Type club in the search box.
  3. Click Search.

script.js · add at the bottom

function searchResources() {
  const query = searchInput.value.trim().toLowerCase();
  const matches = resources.filter((item) =>
    item.title.toLowerCase().includes(query)
  );
  showResults(matches);
}

searchButton.addEventListener("click", searchResources);

✅ Check: only “Coding club” is listed and the status says 1 result(s) found.

Event = click. Action = filter the array. Feedback = the new list and status message.

06

STEP 6 OF 11 · SCRIPT.JS · ADD BELOW

Add Enter and Reset.

  1. Add this code at the bottom.
  2. Type xyz and press Enter.
  3. Click Reset.

script.js · add at the bottom

searchInput.addEventListener("keydown", (event) => {
  if (event.key === "Enter") {
    searchResources();
  }
});

resetButton.addEventListener("click", () => {
  searchInput.value = "";
  showResults(resources);
  searchInput.focus();
});

✅ Check: “No resources match your search.” appears, then Reset brings back all three resources.

08

STUCK? · COMMON FIXES

Read the red error.

  • Nothing happens on clickCheck the id in index.html matches the "#name" in script.js exactly.
  • “… is not defined”A name is spelled differently. Capital letters matter: searchInput ≠ searchinput.
  • “Cannot read properties of null”querySelector found nothing. Fix the id spelling.
  • “Unexpected token”A bracket, quote or comma is missing. Compare line by line with the slide.

The Console shows the line number of the first error. Fix that one first.

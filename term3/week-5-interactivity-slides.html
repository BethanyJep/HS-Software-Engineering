02

STEP 2 · ~20 MIN

Give JavaScript
targets.

<label for="search">Find a resource</label>
<input id="search" type="search">
<button id="search-button" type="button">Search</button>
<button id="reset" type="button">Reset</button>
<p id="status" aria-live="polite"></p>
<ul id="results"></ul>

Unique ids let JavaScript find the input, buttons, status and result list.

03

BUILD · JAVASCRIPT PANEL

Choose elements.
Store data.

const resources = [
  { title: "Revision group" },
  { title: "Science fair" },
  { title: "Coding club" }
];
const searchInput = document.querySelector("#search");
const searchButton = document.querySelector("#search-button");
const resetButton = document.querySelector("#reset");
const status = document.querySelector("#status");
const results = document.querySelector("#results");

Read each const aloud: what value or element does it hold?

04

BUILD · SAFE OUTPUT

Show results.
Safely.

function showResults(items) {
  results.replaceChildren();
  for (const item of items) {
    const listItem = document.createElement("li");
    listItem.textContent = item.title;
    results.append(listItem);
  }
  status.textContent = `${items.length} result(s) found.`;
}

Use textContent for ordinary text. Do not put user or API text into innerHTML.

05

BUILD · USER ACTION

Filter what
matches.

function searchResources() {
  const query = searchInput.value.trim().toLowerCase();
  const matches = resources.filter((item) =>
    item.title.toLowerCase().includes(query)
  );
  showResults(matches);
}
searchButton.addEventListener("click", searchResources);

The event is click. The action is filter. The feedback is the result list and status.

06

PRACTISE · ~25 MIN

Plan for
nothing found.

if (items.length === 0) {
  status.textContent = "No resources match your search.";
}

resetButton.addEventListener("click", () => {
  searchInput.value = "";
  showResults(resources);
});

Add a fourth resource, test a search with no match, then reset to all resources.
